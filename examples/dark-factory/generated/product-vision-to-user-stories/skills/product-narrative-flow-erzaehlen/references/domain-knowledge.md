# Domain knowledge — Big Picture & Narrative Flow erzaehlen

- Story mapping step 2: tell the big picture as a narrative from left to right [^1].
- The horizontal axis of a story map represents steps in a high-level user activity [^2]; the narrative defines that axis.
- Pass: the backbone derived from it is solution-independent; the map is a 2D grid (horizontal is narrative) [^1][^2].
- Pitfall: the flat backlog trap, meaning a linear list without narrative context [^2].
- Kalbach: "Map the big picture" comes right after framing and before exploring details [^1].

[^1]: "Mapping Experiences" (Kalbach 2020) — "Frame the idea … Write your responses down at the top of the map. Map the big picture … Explore … Create a release strategy."
[^2]: "Fifty Quick Ideas to Improve Your User Stories" (Adzic et al. 2014) — "A story map is a grid where the horizontal axis represents steps in a high-level user activity, and the vertical axis represents the software delivery schedule." / "put it on crutches and ship it out."
