# Domain knowledge — Ziel & Kennzahlen festlegen (Why)

## Goals and OMTM (1.2.1)

- Impact mapping has four levels in order: Goal (why, a measurable KPI) → Actors → Impacts → Deliverables [^1].
- OMTM (adopted 2026-09-25): 1.2.1 fixes one One Metric That Matters for the product's current stage and places it on the AARRR funnel
  (Acquisition, Activation, Retention, Revenue, Referral) instead of listing KPIs loosely [^2].
- Pass: goals are business outcomes, not solution mandates [^1].
- Pitfall: a feature as goal or impact ("build a mobile app") [^1].

## Trace chain (Gedächtnis §10.2)

- Mandatory chain: AC → ST → UT → EP/ACTV → (OPP | JOB) → IMP → GOAL → VIS.

[^1]: "Fifty Quick Ideas to Improve Your User Stories" (Adzic, Evans, Korac 2014) — "capture user stories, epics, tasks, product ideas – all the deliverables that could potentially cause a positive impact … Then treat them as options, not as commitments."
[^2]: "Lean Analytics" (Croll, Yoskovitz), via notebook answer 2026-09-25 — "define a single OMTM suited to the product's current stage, using Dave McClure's AARRR (Pirate Metrics) framework."
