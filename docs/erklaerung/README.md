# lanecraft erklärt

Sechs Excalidraw-Blätter, die in dieser Reihenfolge lanecraft für Neue erklären. Die
`.excalidraw`-Dateien lassen sich auf [excalidraw.com](https://excalidraw.com) öffnen und ändern; die
PNGs sind die gerenderten Ansichten.

| Blatt | Frage, die es beantwortet |
|---|---|
| `00-problem` | Welches Problem lösen wir, und wann lohnt sich lanecraft? |
| `01-idee` | Was macht lanecraft? Prozess zeichnen, Pipeline, Agenten/Skills/Hooks bekommen |
| `02-pipeline` | Wie läuft die Übersetzung ab, und wo entscheidet der Mensch? |
| `03-bausteine` | Was sind Skill, Agent, Hook, Workflow und Kontext? |
| `04-kontext` | Aus welchen Schichten besteht der Kontext eines Schritts? |
| `05-mapping` | Was wird aus welchem BPMN-Element? |

Vorschlag für 15 Minuten: mit 00 beginnen, dann 01 zeigen, danach 03 (Begriffe klären), dann 05 und 02, zum Schluss 04.

Zum Ändern: `.excalidraw` in die Canvas laden (`npx -y mcp-excalidraw-server import <datei> --replace`),
bearbeiten, mit `export --out <datei>` zurückschreiben.
